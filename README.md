# Student Admission Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis on a cleaned Student Admission Records dataset using Python.

The analysis examines descriptive statistics, numerical distributions, categorical variables, relationships between features, admission patterns and outliers.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Features

- Name
- Age
- Gender
- Admission Test Score
- High School Percentage
- City
- Admission Status

## Analysis Performed

1. Loaded and inspected the cleaned dataset.
2. Examined the dataset structure and data types.
3. Generated descriptive statistics.
4. Analysed numerical and categorical distributions.
5. Created histograms, count plots, scatter plots and box plots.
6. Examined correlations between numerical variables.
7. Compared academic scores with admission status.
8. Detected outliers using box plots and the IQR method.
9. Answered key questions using summary statistics.
10. Generated a short EDA report.

## Files

- `Task_2_Exploratory_Data_Analysis.ipynb` — complete Jupyter Notebook
- `cleaned_student_admission_records.csv` — cleaned dataset
- `Task_2_EDA_Report.md` — summary report, when included
- Summary CSV files — business, city, gender and outlier summaries
